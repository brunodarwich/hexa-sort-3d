# Política de Segurança — Hexa Infinity

## Versões com Suporte a Atualizações de Segurança

| Versão | Suportada          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Relato de Vulnerabilidades

A segurança dos usuários e da infraestrutura do **Hexa Infinity** é tratada com máxima seriedade. Se você descobrir uma vulnerabilidade de segurança, por favor siga estas diretrizes:

1. **Não abra uma issue pública** no GitHub para relatar problemas de segurança.
2. Envie um e-mail diretamente para:
   - **Contato de Segurança**: `brunodarwich@gmail.com`
   - **Assunto**: `[SEGURANÇA] Relato de Vulnerabilidade - Hexa Infinity`

### Informações Recomendadas
Ao relatar uma vulnerabilidade, inclua:
- Descrição detalhada da vulnerabilidade encontrada.
- Passos reproduzíveis ou Prova de Conceito (PoC).
- Impacto potencial estimado (ex: confidencialidade, integridade de pontuações, pagamentos).
- Sugestão de remediação (se aplicável).

### Nosso Compromisso
- Confirmaremos o recebimento do seu relato em até 48 horas úteis.
- Analisaremos a gravidade e desenvolveremos uma correção antes de qualquer divulgação pública.
- Agradecemos e reconhecemos pesquisadores que praticam divulgação coordenada e responsável.
